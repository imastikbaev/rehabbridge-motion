# Размещение

Рабочая версия: https://rehabbridge-motion-admit-2026.vercel.app/

Приложение статическое. Backend и переменные окружения не требуются.

## Из репозитория на Vercel

В корне есть vercel.json: установка — npm ci, сборка — npm run build, результат — dist. При сборке scripts/assets.mjs получает официальные модели и проверяет их хеши; сборочной среде нужен доступ к сети.

## На другом статическом хостинге

```sh
npm ci
npm run build
```

Опубликуйте содержимое dist целиком, включая vision и models. Не копируйте node_modules и служебные файлы проекта. Нужен HTTPS; по обычному HTTP на телефоне камера недоступна. WASM должен отдаваться как application/wasm, модели .task — application/octet-stream. Клиентских маршрутов нет, SPA rewrite не нужен.

В index.html установлена CSP connect-src 'self' blob:, запрещающая внешние соединения. Blob нужен для локальной передачи загруженного WASM в MediaPipe. В vercel.json также заданы запрет микрофона, разрешение камеры своему origin, nosniff и no-referrer.

## Проверка

```sh
CHECK_BASE_URL=https://rehabbridge-motion-admit-2026.vercel.app npm run check:production
```

Скрипт проверяет загрузку моделей и WASM, искусственную камеру, мобильную ширину, отсутствие ошибок JavaScript и внешних запросов. После этого нужен отдельный ручной прогон с реальной камерой.

Опубликованная версия 29.09.4 прошла эту автоматическую проверку. Исторически она загружена из локальной служебной папки .deploy-vercel (готовая копия dist). Папка и привязка аккаунта в Git не входят. Новый репозиторий не подключается к автодеплою автоматически.
