# RehabBridge Motion — продуктовая гипотеза

Пользователь: человек после инсульта с уже назначенной программой, при необходимости с помощью близкого. Задача: пройти последовательность домашних заданий с понятной обратной связью и журналом выполнения. Масштаб проблемы не считается доказательством пользы именно этого приложения.

Реализованный прототип: выбор одной руки, три разных движения, полный цикл повтора, отдых, старт/переход/повтор раскрытием кисти с резервными кнопками, локальный результат. Диапазоны и повторы по умолчанию — демонстрационные, не терапевтическая дозировка. Командный жест требует сгибания и возврата локтя, поэтому не универсален. До пилота нужно совместно с реабилитологом и пользователями проверить доступность, наблюдаемость и пользу.

Не определяем безопасность, боль, спастичность, клиническую правильность или восстановление. Не увеличиваем нагрузку. Не переносим Kinect-метрики. Нужны интервью, экспертный выбор заданий и независимая проверка webcam с информированным участием людей; эта работа пока не проведена.

Источники для границ проектирования, не валидация продукта:
- NICE NG236, индивидуализация 1.2.19, двигательная реабилитация 1.13, повторение функциональных задач 1.13.20: https://www.nice.org.uk/guidance/ng236/chapter/Recommendations
- American Stroke Association, ограничения движений плеча: https://www.stroke.org/en/about-stroke/effects-of-stroke/physical-effects/managing-pain/shoulder-pain
