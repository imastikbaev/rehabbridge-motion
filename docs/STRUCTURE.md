# Документация

Для знакомства с проектом достаточно README в корне.

| Файл | Содержание |
| --- | --- |
| REQUIREMENTS.md | Соответствие требованиям кейса |
| DEMO.md | Сценарий демонстрации |
| VERIFICATION.md | Фактически выполненные проверки и их ограничения |
| DEPLOY.md | Сборка и публикация по HTTPS |
| SUBMISSION.md | Что приложить при сдаче |
| AUDIT.md | Найденные проблемы и история исправлений |
| PRODUCT_DIRECTION.md | Продуктовая гипотеза |
| archive-orbita/ | Исторические материалы первого варианта, не текущий продукт |

PNG и production-check.json создаются проверками, в Git не включаются. Код и unit-тесты находятся в src, браузерные тесты — в tests. Модели и WASM скачиваются командой npm run assets и в репозиторий не входят.
