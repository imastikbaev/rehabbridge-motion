# Демонстрация RehabBridge Motion · 2–3 минуты

Показывает участник команды без выдачи демонстрации за клиническое испытание. Для пациента нужны согласованные упражнения и условия специалиста. Камера видит плечи и выбранную руку, для пальцев — ладонь достаточно крупно.

1. «Помогаем пройти домашнее задание: понять движение, выполнить полный повтор и увидеть итог. Это прототип сопровождения назначенной программы, не назначение лечения».
2. Выбрать руку и **1 повтор** для короткого демо, включить камеру. После настройки оставить выбранную руку у корпуса в исходном положении: отсчёт 3 секунды запускает практику без кнопок.
3. Сгибание: сначала неполное движение, показать конкретную подсказку; затем заданная отметка, удержание и возврат. Счёт изменяется только после возврата.
4. Отдых без таймера. Согнуть/вернуть локоть для перехода. Боковое движение к отметке и возврат. Кратко выйти из кадра: счёт на паузе, незавершённый повтор сброшен.
5. Следующее задание: раскрытие четырёх пальцев и возврат. Итог по трём заданиям, локальная история без личных данных. Повторить жестом или кнопкой, затем выключить камеру.

Техническое пояснение: две готовые модели дают landmarks, новая логика нормализует относительно плеч, привязывает кисть к выбранной руке, сглаживает и считает цикл с hold/cooldown. Без webcam-метрик и медицинской оценки. Старый RehabBridge создан до хакатона, его файлы не переносились; помощь Codex раскрыта.

Если камера/движение не распознаются: честно показать dev `/?lab` как синтетический тест логики. Это не live webcam-валидация и не замена обязательной проверке реального человека.
